How scoring works

Scores shown for each selected model

A
Reference pass rate

Checks each answer against the selected contains, equals or not-contains rule.

B
Baseline agreement

Compares normalized answer text with the first selected model. Matching text does not guarantee correctness.

C
Repeat consistency

Repeats each case and measures how often a model returns the same normalized answer.

!
Not a hallucination-rate meter

Reference checks and exact-text agreement are screening metrics, not semantic grading or validated factuality measurements.

Measurement scope

What these readings do and do not say

SYSTEM-WIDECPU / RAM

Includes Windows, browser, the dashboard and every other running application.

DEVICE-WIDEGPU / VRAM / power

May include any application using the NVIDIA GPU. Do not attribute the total to Ollama alone.

RUNTIME-REPORTEDOllama allocation

Reported model allocation is more directly related to Ollama but is not a per-layer trace.

PROCESS-LEVELOllama RSS / CPU

Includes runtime overhead and may not precisely isolate one model or one inference request.
